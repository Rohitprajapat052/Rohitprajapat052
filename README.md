## 📌 Featured Projects

### 🎙️ [SocialSieve](https://social-sieve.vercel.app/): AI Voice & Text Analysis Platform
*Turns voice recordings and text into transcripts, summaries and action items.*
- **Full-stack AI SaaS** with JWT authentication, file upload and usage tracking (monthly limits and tiers).
- **OpenAI Whisper** for speech-to-text and **Llama 3.3-70b on Groq** for summarization and action-item extraction.
- Chose Groq for faster inference (about 8s down to 3s); 500+ analyses processed on zero-cost infrastructure.
- Deployed on Vercel (frontend) and Render (backend), with Cloudinary for audio storage.
- **Stack**: React · TypeScript · FastAPI · MongoDB (Beanie ODM) · Groq API
- [🔗 Live demo](https://social-sieve.vercel.app/)

### 🏢 [LibraryDesk](https://github.com/Rohitprajapat052/LibraryDesk): Multi-Tenant Library & Reading Room Management SaaS
*Production-ready web application designed specifically for Indian study libraries and reading rooms.*
- **Multi-Tenant Architecture**: Complete database isolation with server-side assertion checks protecting independent library tenants.
- **Decimal-Safe Financial Engine**: Integer paise storage, automated FIFO payment allocation, advance multi-month credit tracking, and printable receipts with amount in words.
- **Calendar-Aware Billing**: End-of-month date clamping (e.g. 31 Jan to 28 Feb) and Indian date standards (DD/MM/YYYY).
- **Physical Space Matrix**: Visual Floor &rarr; Room &rarr; Seat hierarchy with real-time occupancy and seat transfer workflows.
- **Stack**: Next.js 14 App Router · TypeScript · Prisma ORM · PostgreSQL · Tailwind CSS · Vitest
- [📂 Source code](https://github.com/Rohitprajapat052/LibraryDesk)
