### 🚀 Featured Project

<table>
  <tr>
    <td>
      <h3>🏢 <a href="https://github.com/Rohitprajapat052/LibraryDesk">LibraryDesk</a> — Multi-Tenant Library & Reading Room Management SaaS</h3>
      <p>A production-oriented web application designed specifically for Indian study libraries, reading rooms, and self-study centres.</p>
      <ul>
        <li><b>Multi-Tenant Isolation</b>: Complete database-level isolation protecting independent libraries with strict server-side assertions.</li>
        <li><b>Decimal-Safe Financial Engine</b>: Integer paise handling for zero floating-point errors, automated FIFO payment allocation, advance credit tracking, and printable receipts with amount in words.</li>
        <li><b>Calendar-Aware Billing</b>: Smart end-of-month handling and Indian date standards (DD/MM/YYYY).</li>
        <li><b>Physical Space Matrix</b>: Visual Floor &rarr; Room &rarr; Seat grid with live occupancy and seat transfer capabilities.</li>
        <li><b>WhatsApp Manual Outreach</b>: One-click prefilled polite fee reminder notices directly via WhatsApp.</li>
      </ul>
      <p><b>Stack</b>: Next.js 14 App Router, TypeScript, Prisma ORM, PostgreSQL, Tailwind CSS, Vitest.</p>
